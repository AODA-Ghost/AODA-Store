Política de Privacidade

Última atualização: Janeiro 2026

Em vigor desde 01/01/2026

A AODA Store ("nós", "nosso" ou "AODA") compromete-se a proteger a privacidade dos utilizadores do nosso website e clientes. Esta Política de Privacidade explica como recolhemos, utilizamos, armazenamos e protegemos os teus dados pessoais.

1. Dados que Recolhemos

1.1 Dados fornecidos por ti

  • Nome completo e contacto (e-mail, telefone)
  • Morada de entrega (rua, bairro, município, província)
  • Número de BI/Passporte (quando fornecido voluntariamente)
  • Dados de pagamento (processados pelo gateway de pagamento, não armazenados diretamente por nós)
  • Mensagens enviadas através do formulário de contacto

1.2 Dados recolhidos automaticamente

  • Endereço IP e localização aproximada
  • Tipo de browser e dispositivo
  • Páginas visitadas e tempo de navegação
  • Dados de cookies (ver secção 4)

2. Para Que Utilizamos os Teus Dados

  • Processar encomendas: Entregar os produtos na morada indicada e gerir o pagamento.
  • Comunicação: Enviar confirmações de encomenda, atualizações de envio e respostas a contactos.
  • Melhoria do serviço: Analisar padrões de uso para melhorar a experiência no website.
  • Marketing (com consentimento): Enviar novidades e promoções via newsletter, apenas se subscreveres.
  • Obrigações legais: Cumprir requisitos fiscais e legais aplicáveis em Angola.

3. Com Quem Partilhamos os Teus Dados

  • Transportadoras: Nome, telefone e morada estritamente necessários para a entrega.
  • Gateways de pagamento: Multicaixa Express ou instituições bancárias para processar pagamentos.
  • Autoridades legais: Quando exigido por lei ou ordem judicial.

Nunca vendemos, alugamos ou partilhamos os teus dados pessoais com terceiros para fins de marketing.

4. Cookies

Utilizamos cookies essenciais para o funcionamento do website (como o carrinho de compras) e cookies analíticos para entender como os utilizadores interagem com o site. Podes gerir as preferências de cookies nas definições do teu browser.

5. Armazenamento e Segurança

Os dados são armazenados em servidores seguros. O carrinho de compras utiliza o armazenamento local do browser (localStorage) e não é partilhado com terceiros. Implementamos medidas de segurança adequadas para proteger contra acesso não autorizado, alteração ou destruição dos dados.

6. Os Teus Direitos

Tens o direito de:

  • Aceder: Solicitar uma cópia dos teus dados pessoais que temos armazenados.
  • Retificar: Corrigir dados incorretos ou incompletos.
  • Eliminar: Solicitar a eliminação dos teus dados (sujeito a obrigações legais de conservação).
  • Opor-te: Recusar o uso dos teus dados para fins de marketing direto.

Para exercer qualquer um destes direitos, contacta-nos em privacidade@aodastore.co.ao.

7. Retenção de Dados

Guardamos os dados das tuas encomendas durante 2 anos para fins de garantia e contabilidade. Os dados de newsletter são mantidos até que solicites a unsubscribe. Os dados do formulário de contacto são mantidos durante 6 meses.

8. Alterações a Esta Política

Podemos atualizar esta Política de Privacidade periodicamente. Quaisquer alterações significativas serão comunicadas no nosso website. A data de "última atualização" no topo desta página indica quando foi revista pela última vez.

9. Contacto
